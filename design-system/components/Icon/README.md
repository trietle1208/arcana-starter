# Icon

Arcana's own line icon set: 24px grid, 1.6 stroke, round caps and joins, drawn with `currentColor`.

- Names: home, library, reading, study, journal, settings, search, shuffle, bookmark, pen, check, plus, arrow, turn, info, x.
- Icons sit beside a text label; an icon alone needs `label` (it becomes `role="img"`).
- Colour follows text: `ink` by default, `terracotta-ink` for the active nav item, `olive-ink` in success notices.
- No mystical glyphs (stars, moons, eyes, zodiac) as UI icons.

Consumer provides: `name`, optional `size` (default 20), `label`.
