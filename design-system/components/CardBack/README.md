# CardBack

The back of every card: `midnight` with `gold` line art — a double border with curled corner flourishes, a sun with sixteen rays cradling a crescent moon, a sparkle above and below, a faint ring. It is drawn as one inline SVG (viewBox 284×511) in `currentColor`.

- Mirror-symmetric top to bottom, so a reversed card can never be spotted from its back.
- Original artwork for Arcana; keep it as the only illustrated back.

Consumer provides: nothing (optional `className`).
