# Sparkles

A single burst of 12–16 four-point `gold` sparkles that fly outward, turn and fade (1.1s). `TarotCard` fires one automatically when it is revealed.

- Decorative and one-shot: never loop it, never use it for errors or ordinary saves.
- Renders nothing under reduced motion.

Consumer provides: optional `count`, `seed` (re-key the element to replay).
