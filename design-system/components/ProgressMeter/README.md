# ProgressMeter

A labelled linear meter for learning progress: `olive` fill on an `olive-soft` track, 8px, rounded.

- Always show the numbers ("14 of 22") beside the label — the bar is a summary, not the only signal.
- No streak flames, confetti, levels or points. Progress is described plainly ("You've studied 14 of 22 major arcana").

Consumer provides: `label`, `value`, `max` (default 100), optional `caption`.
