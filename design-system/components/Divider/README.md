# Divider

A separator with a hand-drawn quality: the default is a slightly uneven pencil rule in `line`; `variant="sprig"` sets a small `olive` botanical sprig between two hairlines; `variant="star"` sets three `gold-ink` sparkles — the storybook mark.

- Use one ornamental divider (sprig or star) per screen at most, between major sections: the end of a reading, the top of a journal page.
- Stars belong to moments of ritual (readings, card of the day). Keep everyday panels — lists, settings, forms — plain.

Consumer provides: optional `variant` (`rule` | `sprig` | `star`).
