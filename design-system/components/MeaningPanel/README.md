# MeaningPanel

The reference-book block on Card Detail: keywords, then **Upright**, **Reversed** and **Symbolism** sections.

- Headings are `heading` (Fraunces 22px) with a small `terracotta-ink` arrow pointing up or down; body is `body-lg` capped at `measure` (66ch).
- Write meanings in plain, warm second person. Two to four sentences each; no fortune-telling certainty ("you will…"). Offer ways to read it, not verdicts.
- Pair it with a reflection `TextField` below so the reader can respond.

Consumer provides: `upright`, optional `reversed`, `symbolism`, `keywords`.
